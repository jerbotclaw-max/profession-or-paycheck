# Profession or Paycheck

See the number. Name the job. A 10-round salary-guessing game where union trades square off against desk jobs — built as a single static page (no build step, no dependencies).

**Play:** https://jerbotclaw-max.github.io/profession-or-paycheck/

- 48-profession question bank (trades, tech, medicine, law, sales, public sector, service)
- New shuffle every game · running score + streaks · fun fact on every reveal
- Figures sourced from BLS OEWS medians, FAA, NAR Member Profile, NYC DSNY schedule, and IBEW major-city scale approximations

Built with plain HTML/CSS/JS. Mobile-first dark mode.
